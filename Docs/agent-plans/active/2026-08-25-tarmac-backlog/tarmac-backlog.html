Tarmac Backlog

Generated 2026-08-25

  1. Sidebar selection doesn't update the results pane

    Clicking a search in the sidebar list has no visible effect: the row doesn't select and the results pane doesn't switch to the clicked search. Selection should work reliably and drive the results pane to the chosen search.

  2. Sidebar rows: multiline layout and richer UI

    Sidebar rows currently render as a single line of text. They should wrap onto multiple lines (e.g. route on one line, dates/price on another) and show more detail per row so a search's route, dates, and last known price are visible at a glance, with better visual hierarchy overall.

  3. Add Market to Preferences

    The market field sent on every search request is currently hardcoded to "CH" in three places. Add a Market preference (e.g. defaulting to CH) so it's configurable instead of hardcoded.

  4. Add number of passengers to search forms

    Search forms (one-way and round-trip) should include a number-of-passengers field, defaulting to 1.

  5. Rename "Save" to "Search" and run immediately

    In the new-search forms, the "Save" button should be relabeled "Search" and should kick off a search run immediately on save, instead of requiring a separate click on "Refresh" afterward.

  6. Remove the "Tarmac" window title

    The "Tarmac" navigation title on the main window doesn't add value and should be removed.

  7. Show carrier, departure time, and arrival time in results; fix empty Duration

    The results table only shows a combined outbound/inbound summary and a Duration column. It should also surface carrier, departure time, and arrival time. Separately, the Duration column is currently showing empty and needs to be fixed.

  8. Use marketing_carrier_code for flight number display

    The results table currently formats flight numbers by concatenating carrier_code and flight_number with no separator (e.g. "LX1234"). It should instead use marketing_carrier_code (present in the Ignav API response but not yet modeled in the app) and format it in the standard IATA style with a space, e.g. "LX 1234".

  9. Make the results table sortable, default sort by Price

    The itinerary results table isn't sortable today. Add sorting support, with Price as the default sort column.

  10. Investigate a "buy ticket" link in results

    Explore whether the Ignav API can provide a link to purchase/book the selected fare, and if so, surface it in the results.
